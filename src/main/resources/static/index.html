Proyecto GEMA

Diseñado para que la gestión académica se sienta simple.

GEMA centraliza información que normalmente queda repartida entre planillas, mensajes y archivos. La web conserva los módulos principales de la aplicación JavaFX, pero con una experiencia más rápida, clara y adaptable a celular, tablet y computadora.
